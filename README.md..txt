# CafeFlow — Cafe Management System

CafeFlow is a cafe management system prototype built using Python, Streamlit, and SQLite.

## Features

- Dashboard with cafe performance metrics
- Menu management: add, edit, and remove menu items
- Order management: create orders and update order status
- Payment management: record full and partial payments
- Analytics: sales, popular items, and payment reports
- CSV export for selected records

## Technology Stack

- Python
- Streamlit
- SQLite
- Pandas

## Run Locally

1. Clone this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`

## Project Status

This is a portfolio and learning prototype. It is not yet a production-ready commercial payment system.
