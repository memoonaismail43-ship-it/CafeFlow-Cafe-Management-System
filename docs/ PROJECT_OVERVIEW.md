# CafeFlow — Project Overview

## 1. Introduction
CafeFlow is a Cafe Management System designed to help cafes manage their daily operations through a single application. The system provides features for menu management, customer orders, billing, payment tracking and sales analytics.

## 2. Problem Statement
Many small cafes rely on manual records and spreadsheets to manage orders, calculate bills and track payments. This can lead to calculation errors, inefficient workflows and difficulty monitoring business performance. CafeFlow aims to organise these activities through a centralised digital system.

## 3. Project Objectives
* Simplify menu management.
* Make customer order processing easier.
* Calculate bills automatically.
* Record full and partial payments.
* Track outstanding balances.
* Display sales and business analytics.

## 4. Main Features

| Module | Description |
| :--- | :--- |
| **Overview** | Displays key business metrics and recent activity. |
| **Menu Studio** | Add, edit and manage menu items. |
| **Order Desk** | Create and manage customer orders. |
| **Billing & Invoices** | Generate itemised bills and view totals. |
| **Payments** | Record payments and track balances. |
| **Analytics & Reports** | View revenue, popular items and payment summaries. |

## 5. Technology Stack
* Python
* Streamlit
* SQLite
* Pandas
* Plotly
* GitHub

## 6. Intended Users
* Cafe owners
* Cafe managers
* Cashiers
* Cafe staff

## 7. Project Scope
The current prototype focuses on core cafe operations, including menu management, order processing, billing, payments and reporting. Advanced features such as multi-branch management, employee accounts and online ordering may be considered for future development.

## 8. Expected Outcome
The expected outcome is a functional and user-friendly cafe management application that demonstrates software development, database management and project management skills.
