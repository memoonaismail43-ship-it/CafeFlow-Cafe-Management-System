# CafeFlow — Functional Testing Report

## 1. Project Overview

CafeFlow is a Cafe Management System prototype developed using Python, Streamlit and SQLite.

The application helps cafe staff manage menu items, customer orders, billing, payments and sales analytics.

## 2. Testing Approach

Manual functional testing was performed through the application interface.

Each module was checked to verify that its main features worked as expected.

## 3. Testing Summary

| Module | Test Coverage | Result |
|---|---|---|
| Dashboard | Metrics and recent records | PASS |
| Menu Studio | Add, edit and delete menu items | PASS |
| Order Desk | Create orders, update status and verify totals | PASS |
| Billing & Invoices | Invoice details and bill calculations | PASS |
| Payments | Full and partial payments, balance verification
