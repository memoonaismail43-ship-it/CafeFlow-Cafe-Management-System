# CafeFlow — Functional Testing Report

## 1. Project Overview

CafeFlow is a cafe management system prototype developed using Python, Streamlit, SQLite, Pandas and Plotly.

The application supports menu management, customer orders, billing, payments and business analytics.

## 2. Testing Approach

Manual functional testing was performed through the CafeFlow application interface.

The six main modules were tested using practical operations and temporary test data.

## 3. Testing Summary

| Module | Test Coverage | Result |
|---|---|---|
| Dashboard | Sales metrics, total orders, recent orders and balances | PASS |
| Menu Studio | Add, edit and delete menu items | PASS |
| Order Desk | Create orders, select items, quantities, totals and status updates | PASS |
| Billing & Invoices | Customer details, itemised invoices, prices and totals | PASS |
| Payments | Partial and full payments, outstanding balance verification | PASS |
| Analytics & Reports | Revenue charts, popular items, filters and CSV exports | PASS |

## 4. Testing Results

All six modules passed the manual functional checks performed during this testing session.

The tested operations behaved as expected.

## 5. Defects

No defects were reported during the recorded testing session.

## 6. Testing Limitations

- Testing was performed manually.
- Automated testing has not yet been implemented.
- Performance and security testing remain future work.
- Multi-user testing has not been documented.
- Further validation is required before production deployment.

## 7. Conclusion

CafeFlow successfully passed the recorded manual functional checks across its six main modules.

The prototype demonstrates core cafe management operations, including menu administration, order processing, billing, payment tracking and analytics.

Further testing and improvements are planned to enhance reliability, security and scalability.

## 8. Project Status

Portfolio prototype — six-module manual functional testing completed.
